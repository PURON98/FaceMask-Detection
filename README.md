# 😷 Face Mask Detection System

A deep learning project for detecting face masks using computer vision and convolutional neural networks (CNN). This system was developed during the COVID-19 pandemic to help identify whether individuals are wearing masks properly.

## 🎯 Overview

This project implements two different CNN architectures for face mask detection:
- **VGG16** - Visual Geometry Group model
- **ResNet50** - Residual Network model

## 🚀 Features

- Real-time face mask detection
- Multiple CNN architecture implementations
- High accuracy classification
- Jupyter Notebook implementation for easy experimentation

## 📊 Models

### 1. VGG16 Model
- Transfer learning approach using pre-trained VGG16
- Fine-tuned for binary classification (mask/no mask)
- Implementation in `FaceMaskVGG.ipynb`

### 2. ResNet50 Model
- Deep residual learning framework
- Skip connections for better gradient flow
- Implementation in `FaceMask_Resnet50.ipynb`
